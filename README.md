# SWYNEX Data Cleaning

## Project Overview

This project focuses on cleaning and preparing the Global Air Pollution Dataset from Kaggle using Microsoft Excel.

## Objectives

* Identify and address missing values.
* Check for duplicate records.
* Verify appropriate data types.
* Identify and standardize inconsistent entries.

## Dataset Source

* **Dataset:** Global Air Pollution Dataset
* **Platform:** Kaggle
* **Source:** https://www.kaggle.com/datasets/hasibalmuzdadid/global-air-pollution-dataset

## Tools

* Microsoft Excel

## Work Completed

* Preserved the original dataset in a worksheet named `Raw`.
* Created a separate worksheet named `Clean` for cleaning.
* Replaced missing country names with `Unknown`.

## Validation

Duplicate records, data types, remaining missing values, and inconsistent entries must be checked before the cleaned dataset is considered final.

## Deliverables

* Cleaned Excel workbook.
* This README documenting the project.
